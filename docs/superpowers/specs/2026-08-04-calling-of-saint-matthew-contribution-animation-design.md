# 《圣马太蒙召》贡献动画设计

## 目标

以 `picture.png`（卡拉瓦乔《圣马太蒙召》）取代现有灵脉/山水主题，生成在 GitHub 个人主页 README 中展示的浅色、深色贡献动画。动画必须让贡献日历本身成为一幅低分辨率像素画：先体现当前贡献强度，随后以随机像素显影的方式还原完整原画，并循环播放。

## 画面规格

- 贡献日历固定为 53 列、7 行的日期结构；每个日期格细分为固定 `3 x 3` 像素簇。
- 完整像素画为 `159 x 21` 个方块。方块等宽等高，绝不拉伸。
- 源画按 `159:21` 的超宽比例裁切。裁切窗口横向覆盖全幅原画，纵向中心固定在原图高度的 36%，并在边界处钳制；这保留上半部偏中的高反差区域：暗部、受窗光照亮的面部、中央红金服饰、右侧人物与指向手势。桌面和人物下半身允许裁掉。
- 源图降采样为 16 色的暗金、褐、黑色固定调色板。终态每个方块显示对应的量化原画颜色，不保留原始 PNG 作为 SVG 内嵌位图。

## 贡献数据与初始态

- 工作流通过 GitHub GraphQL 读取仓库所有者的贡献日历，继续使用 `CONTRIBUTION_READ_TOKEN`。
- 一个日期格的 9 个像素共享该日期的贡献等级。
- 无贡献日期的像素为统一近黑色。
- 有贡献日期的像素使用其终态原画色的亮度版本：等级越高，越接近终态颜色。
- 日期、贡献计数与等级保留为 SVG 数据属性和可访问性文本，便于检查和调试。

## 动画

- 单个循环为 18 秒：10 秒随机显影、4 秒完整画面停留、4 秒随机回暗。
- 显影与回暗都作用于单个像素，而非整格同步切换。
- 每个像素的动画排序由日期和坐标构成的固定种子决定。同一份贡献数据重复生成时结果稳定；贡献日历变化时排序可自然变化。
- 显影阶段，全部像素最终抵达其量化后的原画颜色；回暗阶段返回该像素所属日期的初始贡献亮度。
- 采用轻量的 SVG/CSS 或 SMIL 声明实现色彩过渡，不使用滤镜、外部资源、逐帧位图或脚本运行时逻辑。

## 生成与自动化

- 生成器读取本地 `picture.png`，完成裁切、降采样、调色板量化与 SVG 输出。
- 为 Node 增加可锁定的 PNG 解码依赖，并在 GitHub Actions 中安装后运行生成器。
- 保留现有每日定时、手动触发和 `main` 推送触发；成功后自动提交浅色与深色 SVG。
- 输入图片、贡献 API 或生成过程出错时工作流失败且不提交损坏 SVG。

## 验证

- 验证每个日期格恰有 9 个像素，画布为约 `159 x 21` 像素，并且方块没有非等比拉伸。
- 验证无贡献格初始为近黑，有贡献格初始亮度随贡献等级单调增强。
- 验证终态色值来自固定量化像素画，且所有像素都拥有显影和回暗阶段。
- 验证循环时长为 10/4/4 秒，动画排序可复现，且 SVG 不含嵌入 PNG、滤镜或外部图片。
- 验证浅色与深色输出均可生成，并保留贡献日期/计数元数据。
