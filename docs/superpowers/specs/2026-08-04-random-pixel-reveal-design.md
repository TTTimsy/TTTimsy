# 随机像素显影回退设计

## 目标

回退《圣马太蒙召》贡献动画到最初的简洁逻辑：所有原画像素独立、稳定随机地显影和回暗，不显示 contribution 格框、桥接、主节点、光环或拓扑关系。

## 画面与动画

- 画布恢复为 `159×21`；每个逻辑像素为 `1×1` SVG 单位。
- 无贡献日期的初始像素为近黑；有贡献日期按等级显示同一原画色的固定亮度版本。
- `0–10s`：全部 3,339 个像素依日期和子像素坐标生成的固定随机顺序显影。
- `10–14s`：完整原画停留。
- `14–18s`：全部像素按另一稳定随机顺序回到初始贡献态。
- SVG 只保留像素画、日期元数据和像素自身的色彩动画；禁止格框、桥、光环及其他装饰层。

## 验证

- 验证 viewBox 为 `159×21`、有 3,339 个 `1×1` 原画像素和 18 秒循环。
- 验证输出不存在 contribution-cell-frame、pulse-bridge、contribution-root-halo 与 contribution-pulse-topology 标识。
- 验证固定输入的输出字节级可复现，完整态仍使用同一量化原画色。
