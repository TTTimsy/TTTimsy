# 贡献脉冲拓扑图动画设计

## 目标

在现有《圣马太蒙召》`159×21` 像素画基础上，用真实 GitHub 贡献日历控制动画拓扑。观者必须能同时看出日期格结构、贡献热度、连续提交形成的簇与最终还原的名画。该设计取代上一版由每个像素独立随机显影的逻辑。

## 视觉语言

- 全部 53×7 日期格保留细暗金像素框。无贡献格为近黑石质框；有贡献格按等级增强亮度。
- 连续贡献簇呈现为“圣光电路”。簇内贡献次数最高、同分时日期更早的日期格为主节点。
- 主节点带双层框、中心十字闪点和短余辉；等级 4 的格也拥有回响波。其余活跃格为中继节点。
- 真实相邻活跃格之间才出现硬边金色像素桥。桥在波经过时短促亮起，不能跨越空格。
- 每格 `3×3` 像素按传播方向依次点亮：入射边、中心核、出射边。主节点以从中心向外的顺序点亮。
- 完整画面停留时，像素画保持原始 16 色；格框和主节点保持低频呼吸，使贡献结构持续可读。

## 拓扑与贡献规则

- 活跃格使用 8 邻域连接：上下、左右和四个对角方向均视为可连接；跨周边界按日历二维邻接处理。
- 每个活跃簇以主节点为根构造确定性广度优先树。相同距离节点按贡献次数降序、日期升序排序。
- 每格初始态始终有 9 个子像素；等级 0 为近黑，等级 1–4 分别以固定亮度因子 `[0.28, 0.48, 0.70, 1.00]` 显示对应原画色。
- 等级 4 主节点在主波之后发送一次回响波，短暂点亮其周边暗格的金褐色框线；回响不会改变最终原画色。
- 无贡献格的显影时刻由到最近活跃簇的 Chebyshev 距离决定。只有同一层内允许由日期、坐标和贡献值哈希计算小幅稳定扰动。
- 若全年无贡献，则不产生簇、桥、主节点或回响，只保留暗框与完整画面的无数据循环。

## 24 秒循环

1. `0–3s`：初始贡献态静置，突出各日期格热度。
2. `3–11s`：各贡献簇依次从主节点点火，沿真实拓扑边传播；显示桥和 `3×3` 内部流向。
3. `11–16s`：波前由活跃簇向无贡献格扩散，按距离场逐层还原整幅原画。
4. `16–20s`：完整画面停留；格框与主节点低频呼吸。
5. `20–24s`：按反向拓扑与距离场退回初始贡献态。

## 技术边界

- 增加独立纯数据模块，输出活跃簇、主节点、传播树、桥、子像素流向和距离场；SVG 组装不自行推断拓扑。
- 保留 3,339 个原画像素，增加至多 371 个日期格框、1,000 条桥和每簇一个主节点光环。桥按贡献强度降序、日期升序截断。
- 只使用 SVG 矩形、分组和 SMIL/CSS 声明；禁止滤镜、模糊、外部图片、脚本和路径图形。
- 所有排序、延迟和输出均需固定输入可复现。

## 验证

- 覆盖连续、对角、跨周和断开贡献簇的正确划分。
- 覆盖主节点的计数/日期决胜规则、桥不跨空格、`3×3` 的定向点亮和等级差异。
- 覆盖 24 秒五阶段时序、全年无贡献退化行为、首尾不完整周补齐和输出确定性。
- 验证 SVG 包含 3,339 个原画像素、日期格框和受上限约束的桥；最终态使用量化原画色且不含禁用 SVG 元素。
